How MongoDB finds documents

No index: every document is read. Index on a field: all matches are read, everything else is skipped. Lookup by _id: exactly one.

Together vs separately

SQL tables vs MongoDB documents on the same task, with the bookshelf: how many books (B+ trees) each side opens. Product page and delete: MongoDB wins. Shared data that changes: SQL wins. References: use both.
